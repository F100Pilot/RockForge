áudio → arranjos Rocksmith 2014 · API

A divisão Lead/Rhythm é experimental (sem método publicado). O resultado garantido é um bundle para o DLC Builder; o PSARC final exige Wwise. Reveja sempre a transcrição abaixo e confirme a afinação antes de exportar. Não submeta conteúdo de terceiros sem autorização.

Novo job — ficheiro de áudio

Se o ficheiro tiver tags (ID3/Vorbis), os campos vazios são preenchidos automaticamente; se faltar título ou banda nas tags, é pedido que os preenchas. Início (s): corta o áudio a partir deste segundo (ex: 5.3 → ignora os primeiros 5.3s). As notas são transcritas do áudio aparado — ficam naturalmente sincronizadas. Usa 0 para o ficheiro inteiro.

Novo job — URL YouTube

Desativado por defeito no servidor (viola o ToS do YouTube); o pedido devolve 403 salvo se o operador tiver ativado ROCKFORGE_ENABLE_YOUTUBE.

Novo job — Guitar Pro (GP3/GP4/GP5) + gravação

Via de alta fidelidade: notas, trastes, técnicas, tempo e secções vêm exatas do ficheiro. GPX/GP7 não é suportado — exporta como GP5 no Guitar Pro/TuxGuitar.




Sincronização: o offset desloca a partitura inteira para alinhar com a gravação (a partitura não conhece o áudio). Para letra sincronizada usa um ficheiro LRC; a letra embutida no GP só tem tempo ao nível da linha. Os nomes de tones são gravados no XML (tonebase/tonea–toned) e mapeiam-se a tones reais no DLC Builder.
